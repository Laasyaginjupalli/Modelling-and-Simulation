# Machine Learning and Predictive Analytics – Project Report

## Project Overview

This project focuses on applying machine learning techniques to three different datasets: breast cancer diagnosis, flower image classification and Twitter sentiment analysis. It involves analysing data, developing predictive models, interpreting results and evaluating how accurately the models classify different categories.

## Objectives

- Analyse breast cancer data to identify patterns between benign and malignant tumours.
- Use PCA and feature analysis to identify important variables.
- Classify flower images into Daisy and Non-Daisy categories.
- Analyse tweets and identify positive, negative and neutral sentiments.
- Compare predictive model performance and identify classification errors.

## Methodologies & Frameworks

- Exploratory Data Analysis (EDA)
- Principal Component Analysis (PCA)
- Logistic Regression
- Random Forest
- Neural Networks
- Image Classification
- Sentiment Analysis

## Analytics Applications

- Breast Cancer Diagnosis Prediction
- Daisy Flower Image Classification
- Twitter Sentiment Classification
